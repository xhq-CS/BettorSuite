Build a private web application called BettorTracker.

BettorTracker is a simple sports betting insight, player and team trend research, bet tracking, simulated betting, and private social platform.

The app is for personal use and a small invited group of friends. It is not a sportsbook and does not accept, hold, or transfer real money.

## Main Goal

Create a polished responsive web app where users can:

1. Browse leagues, teams, and players
2. View player and team statistics
3. Analyze player prop trends with graphs
4. Enter custom prop lines
5. Track real bets manually
6. Place simulated bets using virtual money
7. View bankroll and betting-performance analytics
8. Follow friends and favorite trusted bettors
9. Create private groups
10. Send direct messages

Use mock data for the first version. Structure the project so a free sports API can be connected later.

## Technology

Use:

* Next.js
* TypeScript
* Tailwind CSS
* App Router
* PostgreSQL-compatible data models
* Prisma ORM
* Recharts for graphs
* Lucide icons

For the prototype, mock the database and sports data if necessary, but create clean types and interfaces that can later connect to a real backend.

Use a modern dark sports-analytics design.

The interface should feel clean and simple, inspired by apps like LineMate, but do not copy their branding or exact layout.

Avoid clutter, overly complex betting tools, +EV calculations, arbitrage features, and predictive scores.

The refresh process should later:

1. Retrieve completed games
2. Add new game records
3. Update player stats
4. Update team stats
5. Recalculate averages
6. Recalculate hit rates
7. Settle supported bets
8. Save the last refresh timestamp
9. Record errors

For the prototype, use mock player, team, game, and betting data.
