# v2.8.0 — Dark Interface & Readability

> The signed-in suite now feels like the product shown on the front page: dark, focused, and easy to read.

This release carries BettorSuite's navy, gold, and mint visual language through the authenticated experience and corrects the light-only accents that made several social and betting surfaces hard to scan.

## Highlights

- **Persistent themes.** Dark mode is the default, light mode remains available, and the preference is saved between visits.
- **Chats built for long sessions.** Direct Messages and groups use a deep conversation canvas, elevated incoming bubbles, clear blue outgoing bubbles, readable metadata, and dark composers.
- **Quieter Daily Cards.** Pick rows are separated with subtle structural lines instead of bright white dividers.
- **Cleaner shared slips.** Outer borders, metric cells, status treatments, and tail actions now sit naturally inside dark chat attachments.
- **Readable discovery and rankings.** Community search and the leaderboard use layered card surfaces with stronger text hierarchy and clearer profit/loss states.
- **A restrained Profit Boost.** The enabled treatment keeps the amber identity without turning the entire control into a pale panel.

## Design approach

- Deep navy is used for the application canvas and conversation wells.
- Card layers are slightly lighter so structure remains visible without white borders.
- Gold is reserved for primary actions and selected navigation.
- Blue identifies conversation activity and outgoing messages.
- Mint and red communicate positive and negative outcomes with text labels and icons retained.

## Accessibility

- Small text is paired with higher-contrast foreground colors on dark surfaces.
- Status is never communicated by color alone.
- Theme switches remain keyboard accessible and announce the destination theme.
- Focus rings remain visible against both themes.

## Compatibility

This is a backward-compatible interface release. It does not change database schemas, API contracts, accounts, wallets, bets, groups, messages, or existing session data.
